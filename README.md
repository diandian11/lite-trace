# 轻迹 LiteTrace 🦶

> 每天轻一点 · 每步留痕迹 —— 运动健康减肥记录小程序

## 快速开始

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版 Mac）
2. 打开工具 → 导入项目 → 目录选 **`miniprogram/`** → AppID 先用「测试号」
3. 编译即可预览；真机预览用「预览」按钮扫码
