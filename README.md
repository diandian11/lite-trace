# 轻迹 LiteTrace 🦶

> 每天轻一点 · 每步留痕迹 —— 运动健康减肥记录小程序（微信小程序 · 个人主体可用）

记录每天运动、饮食与体重变化，见证变轻的自己。纯本地存储、零后端成本、高隐私。

## ✨ 功能特性

- 📡 **实时记录**：室内加速度计计步（自动识别快走/慢跑），户外 GPS 轨迹 + 地图回看（锁屏继续记录）
- 🏃 **运动打卡**：10 种运动类型，MET 公式估算卡路里消耗，支持强度系数
- 🍱 **饮食记录**：内置常见食物库，快速记录每餐摄入
- ⚖️ **体重追踪**：每日称重，趋势一目了然
- 💧 **喝水打卡**：今日饮水 ml 记录
- 📊 **能量收支**：BMR（Mifflin-St Jeor）+ 摄入/消耗一目了然

## 🚀 快速开始

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开工具 → 导入项目 → 目录选 **`miniprogram/`** → AppID 用自己的（或「测试号」）
3. 编译即可预览；真机预览用「预览」按钮扫码

> 提示：户外 GPS 功能需在小程序后台「用户隐私保护指引」中声明「位置信息」与「传感器信息」。

## 📁 目录结构

```
miniprogram/
├── pages/
│   ├── today/    # 今日总览（能量收支、喝水打卡）
│   ├── sport/    # 运动（实时计步/GPS轨迹 + 手动打卡）
│   ├── diet/     # 饮食记录
│   ├── weight/   # 体重记录
│   ├── profile/  # 个人资料与成就
│   └── track/    # 轨迹回看（全屏地图）
└── utils/
    ├── store.js        # 数据层（本地存储封装，可迁移云开发）
    ├── stepcounter.js  # 加速度计步算法（峰值检测+抗抖动）
    ├── geo.js          # GPS 测距/抽稀/配速
    ├── sport.js        # 运动类型库与 MET 消耗
    └── food.js         # 食物库
```
