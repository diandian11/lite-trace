## 4. 技术选型

- **原生小程序**（WXML/WXSS/JS）：无构建依赖，练手最直接，官方工具直接跑
- **本地存储**：wx.setStorageSync 封装（store.js 统一数据层，将来迁云开发只改此文件）
- **v1.1 图表**：ecomfe/echarts-for-weixin
- **v1.2 后端**：微信云开发（云数据库+云函数，届时评估套餐）

## 5. Git 规范

- 分支：`main`（可用版本）+ `dev`（日常开发）
- 提交前缀：`feat:` 新功能 / `fix:` 修复 / `docs:` 文档 / `style:` 样式 / `refactor:` 重构
- 每个 M1 功能点独立提交，出问题可精确回退

## 6. 上线流程（M3 详细步骤）

1. 注册 → 拿 AppID → 填入 project.config.json
2. 类目：工具 > 效率（个人主体）
3. 隐私：后台「用户隐私保护指引」声明——不收集用户信息
4. 版本管理：开发者工具「上传」→ 后台「提审」
5. 审核一般 1~2 天；可能的拒审点：名称占用（换备选名）、类目不符（改工具类）
6. 过审 → 全量发布 🎉
