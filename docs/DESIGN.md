## 1. 项目概述

**轻迹 LiteTrace（缩写 LT）** 是一款运动健康减肥记录微信小程序。
核心理念：**每天轻一点，每步留痕迹。**

- 记录：每日运动（类型/时长/次数）、体重、饮食与能量摄入、喝水
- 激励：连续打卡、成就徽章、目标达成预测、每周小结
- 技术形态：原生微信小程序 + 本地存储（v1.x 可演进云开发）

**目标用户**：减脂/健身人群（首发即 dian 本人，自用型产品）

## 2. 品牌设计

### 2.1 命名

| 项 | 内容 |
|---|---|
| 中文名 | **轻迹** |
| 英文名 | **LiteTrace** |
| 缩写 | **LT** |
| Slogan | 每天轻一点 · 每步留痕迹 |
| 备选名 | 燃卡日记 BurnCal（BC）、每日轻 DailyLite（DL） |

命名含义：「轻」= 变轻/无负担；「迹」= 足迹/记录的痕迹。
双关：运动留下足迹，体重留下轻迹。

> ⚠️ 小程序名称全网唯一。若「轻迹」被占用，注册时依次尝试：轻迹LiteTrace / 轻迹Lite / 燃卡日记。

### 2.2 Logo 设计理念

**图形**：三枚脚印斜向右上、逐枚变小变浅 ——「越来越轻的足迹」。
一个图形讲两件事：坚持运动的足迹 + 持续变轻的过程。

- 主体形状：圆润脚印 × 3（错落排列，最后一枚最实、最大，代表当下）
- 视觉动线：左下 → 右上，传递积极向上
- 圆角方形 App 图标底：渐变青绿（见配色），白色脚印图形
- 最小尺寸：32px 时省略浅色脚印，仅保留主脚印

### 2.4 视觉规范

- **圆角**：卡片 24rpx、按钮 18rpx、小标签 12rpx（圆润=轻盈友好）
- **阴影**：`0 4rpx 16rpx rgba(15,118,110,0.06)`（青调浅影，不用黑影）
- **字号**：页面标题 34rpx 加粗 / 卡片标题 30rpx / 正文 28rpx / 辅助 24rpx
- **间距**：页面左右 24rpx，卡片间 20rpx，卡片内 28rpx
- **风格**：白卡片浮于云雾白背景，信息密度适中，突出数字

## 4. 页面功能明细

### 4.1 今日页（首页）
- 日期 + 问候 + **连续打卡天数**
- **能量收支卡**：进度条 = 摄入 ÷ (基础代谢+运动消耗)；显示 摄入/运动+/基础
- **快捷汇总**：运动时长、饮食条目数、当前体重
- **喝水卡**：+250ml / −250ml 按钮，当日总量
- 空状态引导：「去运动打卡 / 去记录饮食」

### 4.2 运动页
- 表单：类型选择器（10 种内置 + MET 值）× 时长(分钟) × 次数/组数(选填) × 强度(低/中/高)
- 保存即算消耗：`kcal = MET × 体重(kg) × 小时 × 强度系数(0.85/1.0/1.15)`
- 当日记录列表（可删除），底部合计：总时长 / 总消耗

### 4.3 饮食页
- 餐段：早餐/午餐/晚餐/加餐
- **食物库快选**（内置 24 种常见食物，点击自动填名称+千卡）+ 手动输入
- 当日记录列表（餐段分组显示），底部合计摄入

### 4.4 体重页
- 今日称重输入（25~300kg 校验）
- 指标卡：当前 / 目标 / 已减 / 剩余
- 历史记录列表（近 14 条）
- v1.1：趋势折线图（echarts-for-weixin）、目标达成预测（按近 14 天线性回归外推）

### 4.5 我的页
- 资料设置：昵称、性别、身高、出生年（用于 BMR）、目标体重
- 首次记录体重自动设为「起始体重 & 起始日期」
- 成就概览：累计打卡天数 / 累计运动次数 / 累计记录条数
- 数据管理：清空本地数据（二次确认）
- 关于：版本、Slogan

## 5. 数据模型（本地存储 v1.0）

| Key | 结构 | 说明 |
|---|---|---|
| `lt_profile` | `{name, gender, height, birthYear, targetWeight, startWeight, startDate}` | 个人资料 |
| `lt_weight` | `{ "2026-08-25": 72.4, ... }` | 每日体重（日期→kg） |
| `lt_sport` | `{ "2026-08-25": [{typeKey,name,emoji,minutes,count,intensity,kcal,ts}] }` | 运动记录 |
| `lt_diet` | `{ "2026-08-25": [{meal,name,kcal,ts}] }` | 饮食记录 |
| `lt_water` | `{ "2026-08-25": 1200 }` | 每日喝水 ml |

**业务公式**
- BMR（Mifflin-St Jeor）：男 `10w+6.25h−5age+5`，女 `−161`
- 运动消耗：MET 公式（见 4.2），离线可用
- 连续打卡：当日有任意记录（运动/饮食/体重）即算，向前追溯连续天数

## 7. 合规与安全审计

- **主体与类目**：个人主体。类目建议「工具 > 效率」（个人主体不可选医疗健康类目；本程序为记录工具，不做医疗建议）
- **数据安全**：v1.0 全部数据存于用户设备本地（wx.setStorage），不上传任何服务器，零后端、零泄露面
- **隐私要点**：不采集手机号/位置/通讯录；无第三方 SDK；提审时勾选「不收集用户信息」可简化隐私审核
- **健康声明**：我的页展示「本工具数据仅供个人参考，不构成医疗建议」
- **权限最小化**：v1.0 不申请任何敏感权限（无相机/位置/相册）
- **用户动作安全**：清空数据有二次确认；所有删除可重新录入，无不可逆破坏

## 8. 测试要点（验收清单摘录）

- 空状态首次进入不报错（无资料时 BMR 用默认值）
- 跨天刷新：日期切换后今日页数据正确归零重算
- 连续打卡：昨天有记录、今天无记录时显示保留的天数
- 体重校验：非法输入（0/负数/文本/300+）被拦截
- 存储容量：连续记录 90 天数据后读写仍流畅
